# Direct dependencies, pinned to the versions this project's results were produced with.
#
# Three entries are NOT imported by any module and are pinned deliberately:
#   seaborn      -- not used; matplotlib alone draws every figure. Retained only to pin the
#                   environment the stored results were produced in. Remove when that stops mattering.
#   torchmetrics -- held for Experiment 02b, which must reproduce the inherited notebook's
#                   micro-averaged F1 default rather than this project's macro-F1 (D-010).
#   tqdm         -- not used; the trainer prints per-epoch lines instead.
# Three more are imported only indirectly and would break if removed: scipy (sklearn/statsmodels),
# openpyxl (pandas .xlsx engine), ipykernel (nbclient executes the notebook).
# Transitive dependencies are resolved by pip and deliberately not pinned here.
#
# IMPORTANT — torch and torchvision are NOT installable from PyPI for this machine.
# The RTX 5060 is a Blackwell GPU (compute capability sm_120) and needs a CUDA 12.8+ build,
# which lives on PyTorch's own index. Install those two FIRST, with the index URL:
#
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
#
# then:  pip install -r requirements.txt
#
# On a machine with no NVIDIA GPU, drop the --index-url and plain `pip install torch
# torchvision` gives the CPU build. Everything runs, just slower. See RUNBOOK.md.
